# /matriximg/ — fashion collections on the reactions matrix

Mirror of the two files shipped to the `rafaca/freqz` repo
(freqz.lol) in https://github.com/rafaca/freqz/pull/254 — the page
deploys from there and goes live at https://freqz.lol/matriximg/ when
that PR merges. This copy exists because this session's designated
working branch lives in this repository.

- `index.html` — the /matrix/ "Quadrant" reactions deck re-cut for
  fashion: each card is one look, a square image centred inside the
  graph, rated on Hate It/Love It x Boring/Bold with a fashion
  vocabulary for the live reaction word.
- `images.js` — 123 looks from the Fashion & accessories category of
  the European-shows 2026 catalog (designboom / dezeen), slug-derived
  titles, seeded board positions and counts.
